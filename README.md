# AI Resume Analyzer 📄

## 📌 About the Project

AI Resume Analyzer is a frontend web application designed to help job seekers review their resumes and compare them with job descriptions. The project provides a user-friendly interface for resume analysis and career improvement.

This project was developed to practice frontend web development using HTML, CSS, and JavaScript.

## 🚀 Technologies Used

- HTML5 – Structures the web pages.
- CSS3– Styles the interface and layout.
- JavaScript – Adds interactivity and dynamic behavior.

## ✨ Features

- User-friendly interface
- Resume upload interface
- Job description input section
- Resume analysis dashboard UI
- ATS score display interface
- Missing skills and improvement suggestions sections
- Navigation between application sections

*Note: Analysis results and other features depend on the functionality implemented in the current frontend version.*

## 💻 How to Run the Project

1. Clone the repository

2. Open the project folder in VS Code.

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

4. Explore the application interface.

## 🎯 Project Objective

The objective of this project is to build a simple and intuitive resume analysis interface while improving practical skills in frontend development.
